# Agent Guidelines & Repository Architecture

This repository is an intentionally vulnerable web application (`Just-For-Vuln-Test`) designed for security testing and education covering SQLi, XSS, IDOR, Hardcoded Secret fallback, and Path Traversal vulnerabilities.

## Agent skills

### Issue tracker

Issues are tracked using GitHub Issues via `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context repository structure with root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
